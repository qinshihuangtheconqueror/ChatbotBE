## 3. System Scalability Assessment
The current architecture is well-suited for a university-wide chatbot:
- **Compute**: Milvus and Neo4j are running in standalone containers, allowing for easy horizontal scaling if load increases.
- **Data**: 773 knowledge pieces represent approximately 90% of current student-facing regulations. The system handles vector retrieval in <100ms locally.
- **Concurrency**: The background seeding of Neo4j/Milvus ensure that the primary user flow (chatting) is never blocked by long-running data tasks.
